# Caesar Cipher Java

A console-based Caesar cipher program written in Java.

## Features
- Enter plaintext
- Enter ciphertext
- Set a shift value
- Encrypt text
- Decrypt text
- Try all 25 possible shifts
- Menu controlled with switch-case and do-while

## Concepts used
- Java methods
- Scanner
- for loops
- do-while loops
- switch-case
- Strings and chars
- Character codes
